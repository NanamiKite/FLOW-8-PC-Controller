# 用户指南

[English](user-guide.md)

FLOW 8 PC Controller 使用调音台的原生蓝牙低功耗协议控制实机，不用 USB MIDI 作为控制通道。未连接时仍会显示混音界面，但数值只是占位，直到状态同步完成才能操作设备。

## 安装与连接

Windows 上须分别安装 FLOW 8 PC Controller 和 [DirectHCI](https://github.com/NanamiKite/DirectHCI)。在 DirectHCI Control Panel 中启动服务，并准备、选择受支持的蓝牙控制器；FLOW 安装包不会安装驱动或准备控制器。目前获取控制器会话还需要以管理员权限运行 FLOW 图形程序。详见 [Windows 安装说明](installation.md)。Linux 使用系统蓝牙服务；目前没有记录到 Linux 真机验收结果。

1. 打开调音台并让它可以接受远程蓝牙连接。首次使用新的客户端身份时，在调音台上启用 **PAIR REMOTE / PAIR APP**。
2. 打开程序。未连接时可以先点 **扫描** 查找 `FLOW 8 LE`，再点 **连接**。
3. 等待 **已就绪（Ready）**。程序必须收到并应用完整混音状态才会启用控制；扫描、连接、握手和同步中都不等于就绪。

程序首次使用时会生成稳定的客户端身份，以后继续复用。不要随意删除或分享；生成新身份可能需要重新在调音台上配对。

## 使用界面

顶部可以切换 **混音器、舞台、FX1、FX2、MON1、MON2、MAIN、主输出**。从 **设置** 菜单进入 **偏好设置、快照、路由**。点击通道条可选中通道并查看编辑区；通过目标总线标签选择当前显示哪路混音电平。

- **混音器／输入详情：** 查看和调整电平、静音／独奏、增益、高通、EQ、压缩等适用控件。启用 48 V 幻象电源会要求确认；操作前先核实所接设备。
- **MAIN／MON1／MON2：** 显示各自的混音总线和输出控制。切换页面不会暗中改变物理输出路由。
- **FX1／FX2：** 选择效果预设并调整开放的参数。预设名称及部分参数含义仍需实机校准；以调音台回报的状态为准。
- **路由：** 查看信号关系，操作当前连接状态下可用的路由控件。
- **舞台：** 以可视方式查看通道和电平表。**主输出** 是信号拓扑图，不是第二套总线控制。
- **偏好设置：** 语言、界面缩放、显示选项和已支持的设备设置。未识别或未实现的设备设置保持不可用，不会发送猜测的命令。

蓝牙写入可能有延迟。界面中等待确认的值不代表设备已经接受；设备回报的已确认值优先。

## 设备快照

打开 **设置 → 快照**；如果还没有显示槽位名称，点击 **刷新槽位**。这里只管理设备快照，不提供电脑本地快照库。槽位在收到设备信息前可能显示为空闲、已占用或未知。

**保存** 将当前混音状态写入所选设备槽位，可能覆盖原内容；**载入** 会把已存快照应用到正在工作的调音台；**删除** 移除设备快照；**重命名** 修改保存在设备上的名称。执行前核对确认对话框，槽位或作用范围不符合预期时点取消。这些操作已接入程序，但[验证状态](validation.md)尚未声明所有快照操作都完成了真机验收。

## 断开与常见问题

重新扫描或结束会话前先点 **断开**。重连后必须重新同步状态，不会把上次连接的数值当作当前设备事实。

| 现象 | 检查项 |
|---|---|
| 找不到 `FLOW 8 LE` | 调音台电源和远程连接状态、电脑蓝牙；Windows 还要检查 DirectHCI Control Panel 选中的控制器。 |
| Windows 后端初始化失败 | 检查 DirectHCI 服务／控制器状态，并查看其[故障排查文档](https://github.com/NanamiKite/DirectHCI)。FLOW 程序不能修复驱动准备问题。 |
| 连接一直未进入 Ready | 新客户端身份是否已在调音台启用配对；查看界面连接错误和日志。不完整的状态同步不会启用控制。 |
| 控件不可点击 | 确认连接已进入 Ready；未连接界面按设计只读。 |
| 控件回跳 | 调音台回报了不同的已确认值，或写入仍在等待设备确认；先检查连接和设备状态。 |

Windows 常规日志位于 `%LOCALAPPDATA%\FLOW 8 PC Controller\logs`。日志可能包含混音状态和客户端标识，分享前请检查。当前实机能力边界见[验证状态](validation.md)。
